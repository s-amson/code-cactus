# 🌵 CODE CACTUS

**CODE CACTUS** is an interactive, cartoon-themed Computer Science and Data Structures & Algorithms learning web application built as a self-contained single-file HTML experience.

## ✨ Features

- **Interactive Desert Welcome Scene (Day & Night Modes)**:
  - Animated sun, moon, twinkling stars, shooting stars, drifting clouds, and bouncy cactuses with synthesized Web Audio sound effects.
- **16 Data Structures & Algorithms Topic Cards**:
  - Covers *Introduction*, *C++ Re-cap*, *Linked Lists*, *Analysis of Algorithms*, *Stacks*, *Queues*, *Trees*, *Lists*, *Iterators and Sequences*, *Array ADT List*, *Priority Queues*, *Heaps*, *Maps*, *Hash Tables*, *Binary Search Trees*, and *Graphs*.
- **Introduction Topic Page**:
  - Full-screen two-column learning path layout:
    - **Learn the formal way**: *Lecture Slides* and *Labs*
    - **Learn the fun easy way**: *Theory* and *Practical*
- **LinkedList Express Game**:
  - **Theory Mode**: 18 timed trivia rounds based on course lecture slides with category wedges and streak bonuses.
  - **Practical Mode**: Step-by-step interactive C++ coding challenges (`push_front`, `push_back`, `pop_front`) that animate train carts and pointer links in real time.

## 🚀 Quick Start

### Run Locally
Open `index.html` (or `code-cactus.html`) directly in any modern web browser—no build step or server required.

### Deploy to GitHub Pages
1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/code-cactus.git
   git branch -M main
   git push -u origin main
   ```
2. In your GitHub repository, go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
